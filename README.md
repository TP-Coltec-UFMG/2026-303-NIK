# Nik Is Kind
Um terrível vilão domina sua vila com sentimentos negativos e deixa todos os cidadãos vulneráveis!
Cabe a você salvar todos os membros da vila por meio de diversos _minigames_ e se fortalecer para vencer
o terrível vilão!

## Características Gerais
Plataforma: PC

## Menu Inicial
![Imagem do Menu Inicial](readMeImages/menu.png)
_(Imagem do Menu Inicial, mostrando o título e alguns botões no jogo)_

O menu acessível consiste em:
- Jogar
- Opções
    - Filtros de daltonismo
    - Redução de efeitos do menu
    - Fonte de fácil leitura
    - Edição de Controles
- Sair, que facilita a leitura de informações importantes da tela.
