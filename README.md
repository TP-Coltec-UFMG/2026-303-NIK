## Características Gerais
Plataforma: PC

Entrada: Mouse e Teclado

Requisitos: Batata Cozida ou Purê de Batata em formato de dispositivo eletrônico

## Menu e Acessibilidade
![Imagem do Menu Inicial, mostrando o título e alguns botões no jogo, como "Jogar" e "Configurações"](readMeImages/tela_opções.png)

No menu inicial, estão disponíveis:
- Continuar Jogo *(quando existe um jogo salvo)*
- Novo Jogo
- Opções
- Sair

Em **Opções**, é possível acessar:
- **Configurações**
    - Volume master
    - Volume dos efeitos sonoros
    - Volume da música
    - Edição dos controles
- **Acessibilidade**
    - Filtros de daltonismo e intensidade
![Imagem do Menu Inicial, mostrando o título e alguns botões no jogo](readMeImages/daltonismo.png)
    - Menu circular
    - Idioma (português, inglês ou espanhol)
    - Fonte de fácil leitura
![Imagem do Menu Inicial, com uma fonte mais fácil de ler do que a padrão](readMeImages/tela_opções_fonte.png)
    - Eventos rápidos nos minijogos
    - Guia de caminhos
    - Elementos piscantes

As alterações podem ser salvas dentro das telas de configurações e controles. No jogo, os controles padrão são **WASD** ou **Setinhas** para movimentação e **E** ou **ESPAÇO** para interagir.
![Imagem do Menu de Controles, com opções para alterar os controles](readMeImages/tela_opções_controles.png)
